\section*{StableFill Complex Integration Fixture}

This document is intentionally long and varied. It checks inline values, ragged
table layouts, standard errors above and below estimates, escaped ampersands,
comment safety, and tables that carry table-style tags but are not intended to
be filled. The sample contains {{val:sample_size|,.0f}} observations and
represents {{weighted_population|,.0f}} people. Mean income is
{{mean_income|,.1f}}, median income is {{median_income|,.1f}}, employment is
{{employment_rate|.1%}}, and the headline p-value is significant{{p_value|*}}.
The source is {{survey_label}}. Text such as A \& B, AT\&T, R\&D, and Price

\section*{Tables That Should Stay Stable}

Some tables in a paper are already final. They may still have labels that look
like table tags, but without placeholders their contents should remain exactly
as authored.

\begin{table}[!htbp]
