StableFill
==========

StableFill updates LaTeX, LyX, and Markdown documents from plain text result
files. Start with the [Getting Started](getting-started.md) guide, then see
[Inline Values](usage/07-inline-values.md) and
[LaTeX Economics Tables](usage/08-latex-economics.md) for the main modern
workflows. Use [Annotation Mode](usage/10-annotations.md) when you want to
preview values next to placeholders while drafting. For troubleshooting and the
large regression fixture, see [Diagnostics and Testing](usage/09-diagnostics-testing.md).
